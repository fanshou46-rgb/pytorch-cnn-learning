# 三组配对种子的增强实验

种子预先设为 42、43、44。同一组只改变是否使用训练增强；跨种子同时改变初始化、数据划分、数据顺序和增强随机数。固定两组卷积网络、batch=64、Adam(lr=0.001)、最多 20 轮、验证损失早停 patience=3。每个种子有自己的 50,000/10,000 训练/验证划分，模型使用验证损失最低轮次的权重。

测试使用官方 10,000 张图片，以及固定 −10°/+10° 旋转。两模型收到相同输入，最近邻插值、黑色填充、28×28 画布，模型不更新参数。0° 与干净测试一致，记录中的权重 SHA-256 已核对。

| 43 | -10° | 97.09% | 98.35% | +1.26 |

均值 ± 样本标准差（n=3，标准差分母 n−1）。准确率标准差和配对提升标准差均以百分点计。

| 角度 | 基线平均准确率 | 增强平均准确率 | 平均配对提升 |

| -10° | 97.24% ± 0.48 | 98.15% ± 0.23 | +0.91 ± 0.44 |

| +10° | 97.69% ± 0.03 | 98.16% ± 0.20 | +0.46 ± 0.19 |

三组中，增强模型在原图和两个旋转角度下的准确率均高于基线。相对各自的原图平均准确率，−10° 下基线/增强分别下降 1.46/0.97 个百分点，+10° 下分别下降 1.01/0.97 个百分点。绝对准确率更高与旋转后降幅更小是两个指标；并非每组的降幅都改善，例如 seed=44 的 +10° 下，基线下降 0.94 个百分点，增强下降 1.03 个百分点。

这三组结果用于描述本项目在这些随机设置和旋转角度下的表现。增强方案包含旋转和平移，不能单独归因于某一种变换。测试结果不用于挑选种子或重新选择超参数。
