# MNIST CNN

第一个完整的 PyTorch CNN 项目。

## 目标

使用卷积神经网络完成 MNIST 0-9 手写数字分类，并完整实现训练、验证、Early Stopping、测试与单张图片预测。

## Files

- `load_data.py`：数据下载、预处理与 DataLoader
- `network.py`：CNN 网络结构
- `train.py`：训练、验证与 Early Stopping
- `test.py`：测试集评估
- `predict.py`：单张图片预测
- `data/`：本地数据，不提交数据文件
- `models/`：本地模型权重，不提交权重文件
