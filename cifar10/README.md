# CIFAR-10 学习项目

当前是基础框架，Python 文件为空，代码由自己逐步完成。

## 编写顺序

1. `load_data.py`：读取数据，观察图片、标签和批次形状。
2. `network.py`：定义 CNN，检查输入 `[N, 3, 32, 32]` 到输出 `[N, 10]` 的形状。
3. `train.py`：划分训练/验证集，完成训练、验证和最佳权重保存。
4. `test.py`：加载最佳权重，在独立测试集上评估。

## 文件存放

- 数据缓存：仓库根目录 `data/`。
- 权重和训练日志：本目录 `models/`。
- 测试指标和图片：本目录 `results/`。
- 环境与依赖：沿用仓库根目录 `.venv/` 和 `requirements.txt`。
