# PyTorch CNN Learning

用于系统学习 PyTorch 卷积神经网络（CNN）的练习仓库。

## 学习路线

1. MNIST 手写数字分类
2. CIFAR-10 彩色图像分类
3. Data Augmentation
4. BatchNorm / Dropout
5. ResNet
6. Transfer Learning

## 当前项目：MNIST CNN

计划覆盖：

- Dataset / DataLoader
- CNN 网络结构
- 训练与验证
- Early Stopping
- Test 测试
- Accuracy / Precision / Recall / F1
- Confusion Matrix
- 单张图片预测
